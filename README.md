# Shape Sorting Adventure 🎮

**Shape Sorting Adventure** is a Java-based 2D arcade game developed using Java Swing. The game challenges players to identify and sort falling geometric shapes into their corresponding slots while avoiding obstacles.

The game features five progressive levels, each introducing different shapes, increasing difficulty, and new challenges.

## 🎯 Features

- **5 Progressive Levels:** Unlock new levels by completing previous ones.
- **Shape Sorting:** Identify falling shapes and place them into their matching slots.
- **Multiple Shapes:** Includes circles, squares, triangles, rectangles, rhombuses, parallelograms, pentagons, hexagons, and more.
- **Obstacles:** Avoid obstacles such as trees, stones, and leaves.
- **Score System:** Earn points by correctly sorting shapes.
- **Timer:** Complete each level within the given time.
- **Sound Effects:** Audio feedback for game events.
- **Restart Option:** Restart a level when needed.
- **Level Progression:** Unlock new challenges as you advance.

## 🚀 How to Run

### Prerequisites
- Java JDK installed.
- Any Java IDE (IntelliJ IDEA, Eclipse, or NetBeans) or a terminal.

### Run Using an IDE

1. Clone or download this repository.
2. Open the project in your preferred Java IDE.
3. Make sure all image and audio resources are included.
4. Locate `Main.java`.
5. Run the `Main` class.

### Run Using Terminal

Compile the Java files:

```bash
javac *.java
```

Run the game:

```bash
java Main
```

## 🎮 How to Play

1. Launch the game.
2. Start from Level 1.
3. Observe the falling geometric shape.
4. Sort the shape into its corresponding slot.
5. Avoid obstacles while playing.
6. Earn enough points to complete the level.
7. Unlock and play the next level.
